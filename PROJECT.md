# 🚰 Peepit - Project Summary

## Overview

**Peepit** is a production-ready, custom water bottle ordering system built with PHP 8+ following the MVC architecture. It provides a complete solution for businesses that want to offer customizable water bottles with various sizes, colors, and label designs.

## Project Information

- **Project Name:** Peepit
- **Type:** Web Application
- **Language:** PHP 8+
- **Architecture:** MVC (Model-View-Controller)
- **Database:** MySQL 5.7+ / MariaDB 10.3+
- **License:** MIT
- **Status:** ✅ Production Ready

## Technical Architecture

### MVC Structure

```
app/
├── Core/               # Framework core classes
│   ├── Controller.php  # Base controller
│   ├── Database.php    # Database singleton
│   ├── Model.php       # Base model
│   └── Router.php      # URL router
├── controllers/        # Request handlers
├── models/            # Data layer
├── views/             # Presentation layer
├── services/          # Business logic
└── helpers/           # Utility functions
```

### Database Schema

**12 Tables:**
- `users` - User accounts
- `bottle_models` - Product models
- `bottle_sizes` - Available sizes
- `color_presets` - Color options
- `label_templates` - Label designs
- `pricing` - Quantity-based pricing
- `orders` - Customer orders
- `order_items` - Order details
- `email_logs` - Email tracking
- `user_analytics` - User tracking
- `settings` - System settings

### Security Layers

1. **Input Layer:** Sanitization, validation
2. **Processing Layer:** CSRF validation, authorization
3. **Database Layer:** PDO prepared statements
4. **Output Layer:** HTML escaping
5. **Session Layer:** Secure cookies, regeneration
6. **File Layer:** Upload validation, MIME checking
7. **Transport Layer:** HTTPS enforcement
